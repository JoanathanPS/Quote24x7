System Requirements Calculator

Estimate the hardware needed for different monitoring setups using the System Requirements Calculator. Select your OS Type, choose the category, sub-category, and resource, then enter the details to get system sizing recommendations.

NoteThe system requirements listed below are based on a system running only the OS and On-Premise Poller processes. Additional memory and resources may be required for other processes running on the system.

Frequently Asked Questions

How do I use this calculator to estimate the system requirements?›
  1. Start by selecting your OS type: Linux or Windows.
  2. Add monitoring components using the plus icon + in the data table.
  3. In each row, select the Category and the Sub-Category.
  4. Then enter quantities like Total Devices, Interface Count, Total Performance Metrics, and Poll Frequency.
  5. Click the show button beside Advanced Options to provide values for Monitoring Protocol, Availability Protocol, and Network Latency.
  6. Click Calculate to see CPU, Memory, and Disk requirements.
How do I add multiple monitoring resources to my configuration?›
Click the plus button + in the Actions column to add a new row. Each row represents a monitoring resource. You can add as many rows as needed. To duplicate an existing row with all its settings, use the duplicate button ⧉ instead.
What are Advanced Options and when should I use them?›
Advanced Options let you customize settings like Monitoring Protocol, Availability Protocol, and Network Latency for specific resources. Note that Advanced Options are not available for all resources but only those that support customizable settings. Click show next to Advanced Options in any row to expand and modify these settings. If you don't customize them, the calculator uses default values shown in the Default Values section below the results.
How do I modify or remove items from my configuration?›
  1. To remove a row, click the minus button in the Actions column.
  2. To modify values, simply change the numbers in the input fields or select different options from the drop-down menu. Then, click Calculate again to update the results.
  3. Use the Reset button to clear all data and start over.
Can I save or print my configuration and results?›
Yes. You can use the Print button at the bottom of the results section. This opens your browser's print dialog where you can save as a PDF or print to paper. The print view includes your configuration, results, and default values used in calculations.
What fields do I need to fill out for performance monitoring for network devices?›

You can provide the following details to start monitoring network device performance:

  1. Category: Select Network Monitoring.
  2. Subcategory: Select Performance Monitoring.
  3. Total Devices: Enter the number of devices.
  4. Interface Count: Enter the total count of interfaces across all devices.
  5. Total Performance Metrics: Enter the count of performance metrics across all devices that you wish to monitor.
  6. Poll Frequency: Select your preferred value from the drop-down menu: 1 minute, 5 minutes, 15 minutes, or 30 minutes.
  7. Advanced Options: Click show beside Advanced Options to configure Monitoring Protocol, Availability Protocol, and Network Latency settings.
How do I add agentless server monitoring to the calculator?›

To calculate the count of machines required for agentless server monitoring, provide the following details:

  1. Category: Select Network Monitoring.
  2. Subcategory: Select Agentless Server Monitoring.
  3. Total Devices: Enter the required number of servers to be monitored.
  4. Interface Count: Enter the total number of network interfaces to be monitored.
  5. Total Performance Metrics: Additional performance metrics across all devices. Select Poll Frequency for how often to check servers. In Advanced Options, you can choose between SNMP v1/v2c, SNMP v3, or WMI as the monitoring protocol depending on your server type.
What fields do I need to fill out for switch stack monitoring?›

To determine the number of machines to be required for switch stack monitoring, provide the following details:

  1. Category: Select Network Monitoring.
  2. Subcategory: Select Switch Stack Monitoring.
  3. Total Switch Stacks: Enter the number of switch stacks.
  4. Total Switch Stack Interfaces: Enter the total interface count across all switches across all the stacks in Total Switch Stack Interfaces. Choose your Poll Frequency. Advanced Options allow you to customize monitoring protocol (SNMP v1/v2c or v3), availability protocol, and network latency based on your environment.
How do I add WLC monitoring to the calculator?›
Select Network Monitoring as the Category and WLC Monitoring as the Subcategory. Enter the number of wireless controllers in Total WLCs and the total number of access points across all controllers in Total Access Points. Select the Poll Frequency for monitoring intervals. Use Advanced Options to configure Monitoring Protocol, Availability Protocol, and Network Latency if your wireless infrastructure has specific requirements.
What fields do I need to fill out for configuration management?›
Select Network Monitoring as the Category and Configuration Management as the Subcategory. Enter the total number of network devices whose configurations you want to back up and track in Total Devices. Choose the Poll Frequency (typically one hour to 24 hours for configuration backups). In Advanced Options, you can adjust for configuration file size (small, medium, or large) and network latency.
How do I add flow analysis to the calculator?›
Select Network Monitoring as the Category and Flow Analysis as the Subcategory. Enter the number of interfaces generating flow data in Total Interfaces. The Poll Frequency is set to five minutes by default. In Advanced Options, you can specify Flow Rate (low, medium, or high based on flows per second) and Network Latency to optimize resource calculations.
What fields do I need to fill out for IP address management?›
Select Network Monitoring as the Category and IP Address Management as the Subcategory. Enter the number of subnets you want to track in Total Subnets. Choose the typical Subnet Size from the drop-down (e.g., /24 for 254 hosts or /16 for 65,534 hosts). Select the Poll Frequency for how often to scan subnets (typically 1–24 hours). Advanced Options allow you to adjust for Network Latency.
How do I add different types of web services to monitor?›
In the data table, select Intranet Monitoring as the Category, then choose Web and Application Delivery or Domain and Security as the Subcategory. From the Resource drop-down, select the specific service type you need (REST API, Website, SSL Certificate, etc.). Add multiple rows to monitor different services.
How do I add backup servers to the calculator?›
Add one row for each backup server you want to monitor. Click the plus button +, select Backup Jobs Monitoring as the Category, then choose your backup platform (Veeam Enterprise Manager, Veeam Azure Appliance, or Commvault Command Center). Enter the number of backup jobs in the configuration field for each server.
What fields do I need to fill out for my VMware environment?›
Add separate rows for each resource type you want to monitor: one row for ESX/ESXi hosts (enter host count), one row for VMs (enter VM count), and one row for datastores (enter datastore count). The calculator will automatically sum up the requirements for your complete virtual infrastructure.
How do I add multiple synthetic transactions to monitor?›
Click the plus button + to add a new row, select Synthetic Monitoring as the Category, then choose the transaction type (Web Transaction, RestAPI Transaction, Saas Synthetics, etc.). Enter the number of transactions you want to monitor in the configuration field. Add separate rows for each type of transaction you need.
